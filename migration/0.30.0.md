---

# Migrating to Axle 0.30.0

0.30.0 removes turns from the Agent. An Agent is a _continuation_: it carries
`sessionId` and the active model-facing `messages`, and nothing else. The
transcript — the append-only fold of the event stream — is owned by whoever
consumes the events.

Compaction is reworked into three layers, each with one job. Memory APIs are
removed; use tools or `Instruct.addContext()` instead.

---

## `Agent` — history is gone

`agent.history` is removed. The active conversation is `agent.messages`;
there is no engine-held transcript.

**Before (0.29):**

```ts
const agent = new Agent(config);
await agent.send("Hello").final;
const turns = agent.history.turns;
const messages = agent.history.messages;
```

**After (0.30):**

```ts
import { Transcript } from "@fifthrevision/axle";

const agent = new Agent(config);
const transcript = new Transcript();
agent.on((event) => transcript.apply(event));

await agent.send("Hello").final;
const turns = transcript.turns;
const messages = agent.messages;
```

## `AgentSession` — slimmed down

**Before (0.29):**

```ts
interface AgentSession {
  sessionId: string;
  version: number;
  messages: AxleMessage[];
  archive: AxleMessage[];
  compactions: CompactionRecord[];
  turns: Turn[];
  sessionAnnotations: Annotation[];
}
```

**After (0.30):**

```ts
interface AgentSession {
  sessionId: string;
  messages: AxleMessage[];
}
```

Unknown keys in stored sessions are silently ignored, so old blobs restore
without modification. Turns are now host-owned — persist `transcript.turns`
separately and re-seed with `new Transcript(savedTurns)`.

## Snapshot and restore

`agent.snapshot()` is now `async`. `Agent.restore()` is removed — pass the
session as the second constructor argument.

**Before (0.29):**

```ts
const session = agent.snapshot();
agent.restore(session);
```

**After (0.30):**

```ts
const session = await agent.snapshot();
const agent = new Agent(config, session);
```

## Memory — removed

`AgentConfig.memory`, `AgentMemory`, `MemoryContext`, and `RecallResult` are
removed. The CLI's `ProceduralMemory` is removed.

**For model-directed memory:** provide ordinary retrieval and writing tools in
`AgentConfig.tools`.

**For host-directed context:** retrieve it before sending and attach it to
an `Instruct`:

```ts
const relevant = await memoryStore.search({ userId, query });
const instruct = new Instruct({ prompt: query }).addContext(
  renderMemories(relevant),
  { title: "Relevant memory" }
);
await agent.send(instruct).final;
```

## `Transcript` — renamed from `TurnAccumulator`

| Before (0.29)                    | After (0.30)             |
| -------------------------------- | ------------------------ |
| `TurnAccumulator`                | `Transcript`             |
| `TurnAccumulatorResult`          | `TranscriptApplyResult`  |
| `AccumulatableEvent`             | `TranscriptInput`        |
| `TurnAccumulatorState`           | Removed                  |
| `accumulator.state.turns`        | `transcript.turns`       |
| `accumulator.state.annotations`  | Removed (session-level)  |

The constructor accepts `readonly Turn[]` and shallow-copies it:

```ts
const transcript = new Transcript(existingTurns);
```

## Compaction

### `agent.compact()` return type

**Before (0.29):** `CompactionRecord | null`

**After (0.30):** `Promise<boolean>` — `true` when applied, `false` when no
compactor is configured.

### New `shouldCompactOnTrigger` policy

The compaction callback no longer declines by returning `null` — move that
logic into `shouldCompactOnTrigger`:

**Before (0.29):**

```ts
agent.setCompaction({
  compact: async ({ messages }, { usage }) => {
    if (usage.total < 100_000) return null;
    return summarize(messages);
  },
  triggers: { beforeTurn: true },
});
```

**After (0.30):**

```ts
agent.setCompaction({
  shouldCompactOnTrigger(state, ctx) {
    return state.totalTokens > 100_000;
  },
  compact: async ({ messages }, { usage, signal, trigger, id, emit }) => {
    emit({ progress: 0.5, summary: "Summarizing…" });
    const result = await summarize(messages);
    emit({ progress: 1 });
    return { messages: result.messages, summary: "Reduced by 50%" };
  },
  triggers: { beforeTurn: true },
});
```

### `PromptCompactor` — must wire `shouldCompactOnTrigger`

**Before (0.29):**

```ts
agent.setCompaction({
  compact: compactor.compact,
  triggers: { beforeTurn: true },
});
```

**After (0.30):**

```ts
agent.setCompaction({
  shouldCompactOnTrigger: compactor.shouldCompactOnTrigger,
  compact: compactor.compact,
  triggers: { beforeTurn: true },
});
```

::: danger 0.29 upgrade
Omitting `shouldCompactOnTrigger` means every automatic trigger runs —
the conversation will compact at every configured boundary.
:::

### Compaction events

| Before (0.29)                                   | After (0.30)                                                    |
| ----------------------------------------------- | --------------------------------------------------------------- |
| `compaction:start`                              | `part:start` with `part.type === "compaction"` (status `running`) |
| `compaction:end`                                | `compaction:complete` or `compaction:error`                      |
| —                                               | `compaction:update` with `{ summary?, progress? }`              |

A compaction declined by `shouldCompactOnTrigger` emits nothing.

### `CompactionPart` replaces `CompactionRecord`

`CompactionPart` is self-contained and stateful:

```ts
interface CompactionPart {
  id: string;
  type: "compaction";
  status: "running" | "complete" | "error";
  summary?: string;
  progress?: number; // 0–1
  error?: string;
  // …
}
```

## Event changes

| Removed              | Reason                                    |
| -------------------- | ----------------------------------------- |
| `session:restore`    | Hosts seed their own transcripts.         |
| `compaction:start`   | Replaced by `part:start` lifecycle.       |
| `compaction:end`     | Replaced by `compaction:complete`/`error`. |

Annotation targets no longer include `"session"` — annotations belong to turns
or parts.

## Deleted exports

| Before (0.29)           | After (0.30)                           |
| ----------------------- | -------------------------------------- |
| `History`, `HistoryInit` | Removed — use `agent.messages`         |
| `CompactionRecord`       | Replaced by `CompactionPart`           |
| `AgentMemory`            | Removed — use tools or `addContext()`   |
| `MemoryContext`          | Removed                                |
| `RecallResult`           | Removed                                |
| `TurnAccumulator`        | Renamed to `Transcript`                |
| `TurnAccumulatorResult`  | Renamed to `TranscriptApplyResult`      |
| `AccumulatableEvent`     | Renamed to `TranscriptInput`           |

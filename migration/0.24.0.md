# Migrating to Axle 0.24.0

0.24.0 adds experimental subagent and parallel tool support, plus tool context
helpers and streaming error reporting improvements.

---

## Subagent Tools (Experimental)

`createAgentTool` wraps a bounded `Agent` run as an executable tool:

```ts
import { createAgentTool } from "@fifthrevision/axle";

const researcher = createAgentTool({
  name: "researcher",
  description: "Research a topic and return findings.",
  provider,
  model: "claude-sonnet-4-5-20250929",
  system: "You are a thorough researcher. Research and return findings.",
  tools: [webSearch],
});
```

Child agent turns emit `action:child-event` events, rendered as agent action
parts. Usage from the child is attributed to the provider/model in
`usage.breakdown`, making it possible to reconstruct per-model costs.

```ts
agent.on((event) => {
  if (event.type === "action:child-event") {
    // event.event is a TurnEvent from the child agent
  }
});
```

## Parallel Tools (Experimental)

`parallelize` wraps a tool in a concurrent batch variant that executes
multiple tool calls simultaneously:

```ts
import { parallelize } from "@fifthrevision/axle";

const batchSearch = parallelize(webSearchTool);
```

## Tool Context Helpers

`ToolContext` now includes `reportUsage` for reporting child agent usage back
to the parent:

```ts
const myTool = {
  name: "delegator",
  async execute(input, ctx) {
    const childResult = await ...;
    ctx.reportUsage(childResult.usage);
    return childResult.response;
  },
};
```

## Tool Execution Changes

### `stream()` onToolCall fallback

In `stream()`, when a user-provided `onToolCall` returns `null`/`undefined`,
Axle now falls through to executing the matching registry tool — matching
`generate()`'s existing semantics. Previously this produced a `not-found`
result. Return an explicit `{ type: "error", ... }` result to block a tool.

### `AbortError` not aborting the run

A tool throwing an error merely named `AbortError` (e.g. an internal fetch
timeout) while the run's signal is live is now reported to the model as an
ordinary tool error instead of aborting the run.

## Upgrade Checklist

1. If you use the `stream()` onToolCall returning `null`, verify it now
   falls through to the registry tool — add an explicit error result if you
   relied on the old not-found behavior.
2. Add `action:child-event` handling if you render agent events and use
   subagent tools.
3. Consider calling `ctx.reportUsage()` in tools that consume tokens.

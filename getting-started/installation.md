# Installation

## As a library

```bash
npm install @fifthrevision/axle
```

```bash
pnpm add @fifthrevision/axle
```

```bash
yarn add @fifthrevision/axle
```

## As a CLI

Install the CLI package globally to use the `axle` command anywhere:

```bash
npm install -g @fifthrevision/axle-cli
```

See the [CLI overview](/cli/overview) for usage.

## Requirements

- Node.js 20 or newer.
- An API key for at least one provider (Anthropic, OpenAI, or Gemini), or a
  local OpenAI-compatible endpoint (Ollama, vLLM, etc.).
